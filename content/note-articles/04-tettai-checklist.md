## 撤退判断チェックリスト — 5年間やめられなかった経営者が作った、Yes/Noで答える15問

### 第1章　なぜ撤退できないのか

＜ここから無料公開＞

■「もう少し様子を見よう」の正体

経営がしんどくなった時、一番最初に口から出る言葉がこれだった。

「もう少し様子を見よう」

自分の場合、この言葉を5年間繰り返した。
2020年にコロナで折込広告が消え、月の収支がマイナス400万円になった月。
2021年、赤字が月100万円前後で続いた月。
2023年、追加融資で繋いだ月。

毎回、「もう少し」と言った。

振り返ると、あれは「希望」ではなかった。
「今、判断したくない」という気持ちを、前向きな言葉に置き換えていただけだった。

「様子を見よう」と言っている間は、撤退を考えなくていい。
それが楽だった。正直に言うと、そういうことだった気がする。


■ 撤退＝負けという思い込み

経営者だった5年間、「撤退」を選択肢に入れたことがなかった。

やめたら負け。
やめたら従業員に申し訳ない。
やめたら周りからどう見られるか。

そういう思い込みが、判断を歪めていた。

今になって思うのは、「撤退は負け」ではなくて、
「判断しないまま資金が尽きること」の方が、よほど取り返しがつかない、ということ。

でも当時は、それがわからなかった。
わかりたくなかった、の方が正確かもしれない。


■ 相談しても判断しない構造

赤字が続くと、人に相談する。
税理士に相談した。銀行に相談した。取引先にも相談した。

でも、相談相手は「判断」を返してくれない。

税理士は「数字上はこうです」と言う。
銀行は「融資の可否」を判断する。
取引先は「支払いを待てるかどうか」を判断する。

「この事業を続けるか、やめるか」を判断するのは、経営者しかいない。

自分はそれをわかっていたはずなのに、
「相談した」ことを「判断した」とすり替えていた。5年間、ずっと。

＜ここまで無料公開＞

＜ここから有料＞

### 第2章　判断基準の作り方

この章では、「感覚で悩む」を「基準で判断する」に変える考え方を書く。

自分が5年間できなかったことを、後から整理して言語化したものだから、
「こうすれば正解」ではなく、「こう考えれば、少なくとも毎月ゼロから悩まなくて済む」という話。


■「いくらまでなら続けるか」を決める

月次の赤字額に上限を設定する。

例えば、「月の赤字が50万円を超えたら撤退を検討する」と決める。
額は事業の規模によるが、ポイントは「金額を決めること」自体にある。

自分の場合、赤字が月100万円を超えても「なんとかなる」と思い続けた。
基準がなかったから、100万でも150万でも、毎回「今月だけ」と処理できてしまった。

金額の正解はない。でも、「決めていないこと」は明確に間違いだった。


■「いつまでに回復するか」を決める

「来月には戻るかもしれない」を何ヶ月繰り返すか。

時間軸の撤退基準とは、「この日までに売上が○○万円に戻らなければ撤退する」と決めること。

自分は5年間、期限を設定しなかった。
期限がないから、「もう少し」が永遠に続いた。

3ヶ月後、半年後、1年後。
どこでもいい。期限を決めることが、先送りを止める唯一の方法だった。


■「何が変われば続けるか」を決める

「売上が戻れば大丈夫」と思っていた。
でも、売上が戻る根拠を聞かれたら、答えられなかった。

「コロナが落ち着けば」「折込広告が戻れば」「新規の取引先が見つかれば」。
全部、自分ではコントロールできない外部条件だった。

回復の根拠を1行で書けるかどうか。
書けないなら、それは希望であって根拠ではない。


■ グレーゾーンをなくす

「赤字が続いたら考える」はグレーゾーン。
「月の赤字が50万円を3ヶ月連続で超えたら撤退する」がYes/Noの基準。

グレーゾーンが残っている限り、判断を先送りにできてしまう。
Yes/Noで答えられない基準は、基準ではない。

### 第3章　撤退判断チェックリスト（15問）

以下の15問に、Yes/Noで答えてください。

正直に答えること。
「たぶんYes」「条件付きでYes」は、Noとしてカウントしてください。


**【カテゴリA：資金】**

Q1. 追加の融資や借入なしで、あと3ヶ月事業を続けられるか？
　→ Yes：資金に最低限の余裕がある
　→ No：外部資金に依存している状態

Q2. 今月の固定費（人件費・家賃・リース等）を、今月の売上だけで払えるか？
　→ Yes：損益分岐を超えている
　→ No：毎月、持ち出しが発生している

Q3. 過去6ヶ月で、個人の貯金や生活費を事業に回したことがないか？
　→ Yes：事業と個人の資金が分離できている
　→ No：個人資金で事業を延命している

Q4. 現金残高は、月の固定費2ヶ月分以上あるか？
　→ Yes：最低限のバッファがある
　→ No：1ヶ月以内に資金ショートのリスクがある

Q5. 返済のために新たな借入を検討していないか？
　→ Yes：借入の連鎖に入っていない
　→ No：借金を借金で返す構造になりつつある


**【カテゴリB：売上・回復根拠】**

Q6. 直近3ヶ月の売上は、前年同期比80%以上あるか？
　→ Yes：回復基調、もしくは微減で踏みとどまっている
　→ No：売上が下がり続けている

Q7. 売上が回復する根拠を、1行で書けるか？（「頑張る」「そのうち」以外で）
　→ Yes：具体的な根拠がある
　→ No：希望はあるが根拠がない

Q8. 過去6ヶ月で、新規の顧客・取引先が1件以上増えたか？
　→ Yes：新しい売上の芽がある
　→ No：既存の取引先に依存している

Q9. 主力の商品・サービスの市場が、今後3年で縮小しないと言えるか？
　→ Yes：市場に成長余地がある
　→ No：構造的な縮小トレンドにある

Q10. 競合と比べて、自社を選ぶ明確な理由が1つ以上あるか？
　→ Yes：差別化がある
　→ No：価格以外の競争力がない


**【カテゴリC：経営者自身】**

Q11. 月末に、眠れているか？
　→ Yes：精神的に最低限の余裕がある
　→ No：資金繰りが睡眠を奪っている

Q12. 「撤退した後の生活」を、1つでも具体的に想像できるか？
　→ Yes：撤退を選択肢として考えられている
　→ No：撤退を考えること自体を避けている

Q13. 家族やパートナーに、事業の現状を正直に話しているか？
　→ Yes：状況を共有できている
　→ No：隠している、もしくは実態より良く伝えている

Q14. この事業に、「お金以外の理由」でまだ続けたいと思えるか？
　→ Yes：事業への意志がある
　→ No：惰性、もしくは撤退が怖いから続けている

Q15. 「あと1年同じ状態が続いても耐えられるか？」と聞かれて、Yesと言えるか？
　→ Yes：まだ体力・気力の余裕がある
　→ No：限界が近い


**【判定ガイド】**

Noの数を数えてください。

- **Noが10問以上**：撤退を具体的に検討する段階です。弁護士・税理士への相談を今月中に。
- **Noが5〜9問**：黄色信号。期限を決めて（1ヶ月後を推奨）、もう一度このリストを回してください。
- **Noが4問以下**：現時点では、継続する判断に一定の根拠があります。

大事なのは、「Noが多い＝ダメ」ではないということ。
Noの数が見えること自体が、判断の第一歩。

### 第4章　チェックリストの使い方

■ 月末に15分で回す

月末の資金繰り表を作るタイミングで、このリストを一緒に回す。
15問、Yes/Noで答えるだけだから、15分あれば終わる。

ポイントは、「考え込まないこと」。
直感でYes/Noを付ける。迷ったらNo。
考え込んでいる時点で、たぶんNoだから。


■ 結果を記録する

毎月のNoの数を記録する。

1ヶ月目：No 6個
2ヶ月目：No 7個
3ヶ月目：No 9個

数字が増えているなら、状況は悪化している。
数字が減っているなら、改善の兆しがある。

3ヶ月分並べると、「なんとなくしんどい」が数字で見える。
感覚ではなく、傾向として。


■「No」が増えた時のアクション

Noが前月より増えた場合：
- Noが増えた問の中で、自分でコントロールできるものはどれか確認する
- コントロールできないものが増えている場合、撤退の準備を並行で始める
- 「撤退の準備」＝すぐやめることではない。選択肢を持つこと

Noが10問を超えた場合：
- 弁護士・税理士に「現状を伝える」だけでいい。判断はまだしなくていい
- 「相談＝撤退」ではない。「相談＝選択肢を知ること」

### 第5章　自分の場合

■ 2020年4月に15問を回したら

コロナで折込広告が消えた直後。月の収支がマイナス400万円になった月。

もしあの時、この15問を回していたら：
- カテゴリA（資金）：Noが2〜3個。融資前だったが、まだ現金はあった
- カテゴリB（売上）：Noが3〜4個。「コロナが落ち着けば」が根拠だった
- カテゴリC（自分自身）：Noが1〜2個。まだ気力はあった

合計No：6〜9個。**黄色信号**。

「期限を決めてもう一度チェック」のゾーン。
あの時、3ヶ月後に再チェックしていたら、2020年7月の時点で「売上が戻る根拠がない」ことに気づけたかもしれない。

でも、チェックリストがなかったから、
「もう少し様子を見よう」で5年間走り続けた。


■ 2022年に15問を回したら

融資を2回受けた後。赤字が月50〜100万円で続いていた時期。

もしあの時、回していたら：
- カテゴリA（資金）：Noが4個。借入で繋いでいた。個人資金も投入していた
- カテゴリB（売上）：Noが4個。新規取引先なし。市場は縮小トレンド
- カテゴリC（自分自身）：Noが3個。月末に眠れなくなっていた。撤退後の生活は想像できなかった

合計No：11個。**撤退を具体的に検討する段階**。

2022年に撤退していれば、負債は半分で済んだかもしれない。
あるいは、個人再生で対応できたかもしれない。

正解はわからない。でも、「Noが11個」という数字を見ていたら、
少なくとも「もう少し様子を見よう」とは言えなかったと思う。


■ なぜ当時は作れなかったか

正直に書くと、チェックリストを「作りたくなかった」。

基準を作ると、自分の状況が数字で見えてしまう。
Noが多いとわかってしまう。
「もう少し頑張ればなんとかなる」と思い続けることができなくなる。

基準を作ること自体が怖かった。

でも今は、基準がない方がよほど怖かった、と思っている。

5年間、毎月ゼロから判断するしんどさ。
あれは、お金が足りないことよりも、ずっとしんどかった。

このリストが、「今まさに悩んでいる人」の判断を、少しでも楽にできたらと思う。
