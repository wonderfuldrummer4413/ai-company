B型が2週続けて一番、振り返り型が2週続けて最下位。

### フォローが減った理由（+12 → +2）
1. **新しい人に届かなかった**：先週の「住む場所」はInstagramから26%。今週は最大でも9%で、閲覧のほとんどがホームだった
2. **見た人がフォローする割合も下がった（0.20% → 0.06%）**：同じB型・同じくらいの閲覧でも、10/18「夜中の検索」（読む人に開く締め）＝+4、10/25「家族」（「これ以上書くつもりはない」と閉じる締め）＝+1
3. **A型で質問が集まらなかった**：10/24は意外さが弱く、読んだ人からの返信0

### 新しい発見：「思い込みを覆す型」（10/23）
- 1行目に金額はないが、「会社が潰れても社長個人は関係ない」という思い込みを自分の事実で否定 → 経営者層に届き、返信も付いた

### 勝ちパターン（W43版）
```
【B：広がる型】破産後の不安への、具体的な答え → 2週連続で一番
　「負債8,000万円で破産しても、〇〇は〜」の書き出しは2回使った。次は変える
　締めは「読む人に開く」（閉じない）
【A：返信が集まる型】大きな金額＋意外な一言＋内訳
　意外さが弱いと、質問が集まらない（10/24）
【新：思い込みを覆す型】経営者の常識を、自分の事実で否定する（10/23）
【停止】振り返り型 → 2週連続で最下位
```

### 提案
- 5本の配分：B型2本＋A型2本＋思い込みを覆す型1本。振り返り型は入れない
- B型を「破産したらどうなるのか」シリーズにする（口座・クレジットカード・スマホ）。続きを読む理由＝フォローする理由を作る
- 1行目の数字を変える（8,000万・7,000万は休む。例：1日あたり約4万円）
- 締めは「読む人に開く」
