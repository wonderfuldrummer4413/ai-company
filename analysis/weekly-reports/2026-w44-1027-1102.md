### 分析
1. **金曜が広がった理由**：1行目に、経営者が持っている思い込みを「」のまま置いた → 2〜4行目ですぐに自分の事実（3回とも通った・7,000万円）。同じ型の10/23（680回）は、1行目が「私個人も、一緒に破産した」という自分の話で、思い込みは3行目だった。Instagramに拾われ（74%）、起業・飲食店経営・経営の人に届いた
2. **金曜がフォローにつながらなかった理由**：見た人の74%がInstagramから。Instagramで見た人は、Threadsでフォローしたり自己返信のリンクを開いたりしにくい（リンク先は約0.1%）。締めが「私も、まったく同じことを思っていた。」で、続きを読む理由がなかった
3. **日曜のフォローが多かった理由**：締めの「次は、クレジットカードの話を書こうと思う。」＝続きを読む理由＝フォローする理由（W43のねらいどおり）。1行目が具体的な行動（口座を新しく作った）で、意外さがあった
4. **Cの3本**：木は「〜を潰しても、〜わけではなかった」の書き出しが3回目で効かなくなり、締めも「私の場合は、こうだった。」と閉じた（フォロー0）。水・土はA型なのに、7,000万・8,000万を休んでいるため1行目の金額が「数百万円」（あいまい）と「4万円」（小さい・計算）になり、意外な事実もなかった
5. **いいねと返信の減少**：いいね率は全部下がったが、ホームでの閲覧は先週並み（金曜以外575〜1,474回、W43は233〜1,231回）。返信が1件だったのは、締めに一言で答えられる問いがなかったため。5本とも説明が中心で、場面がなかった

### 勝ちパターン（W44版）
```
【広がる型】思い込みを覆す型（W44で一番）
　1行目＝経営者の思い込みを「」付きで → 2〜4行目＝自分の事実と数字で否定
　例：10/30 融資が通る＝まだ大丈夫（12,834回・IG74%・経営者層）
　弱点：フォローとリンクにつながりにくい
【フォローされる型】シリーズ＋「次は○○の話」の予告
　例：11/1 口座（1,474回・フォロー4・週で一番）
【B：答える型】破産後の不安への、具体的な答え
　「〜しても、〜ではなかった」の書き出しは3回目で効かなくなった（10/29）
【A：金額型】大きな金額＋意外な一言＋内訳
　7,000万・8,000万を休んでいる間は弱い（10/28・10/31がC）
【停止】振り返り型
【避ける】同じ数字の1行目での使い回し／「〜しても、〜ではなかった」の書き出し
```

### 提案
1. 配分：思い込みを覆す型2本＋シリーズ2本（クレジットカード・スマホ）＋A型1本
2. 思い込みを覆す型の1本目は予告で締める（「同じように信じていたことが、もう1つある。次に書く。」）
3. 2本は一言で答えられる問いで締める（例：「同じ経験がある人はいますか」）
4. A型は1本だけ、まだ1行目で使っていない大きな数字で（本社への支払い 毎月800万〜1,000万円）
5. 「〜しても、〜ではなかった」の書き出しを休む
6. リンクは5本すべてを続ける（金曜はリンクありで12,834回）

### 締め方のテスト（W45〜W46）
- 予告で締める投稿 → 閲覧に対するフォローの割合を見る
- 問いで締める投稿 → 読んだ人からの返信の数を見る
- 予告ありのフォローの割合が、ほかの投稿の2倍以上なら「効果あり」
