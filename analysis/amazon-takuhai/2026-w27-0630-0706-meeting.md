## 2. マーケティング部｜勝ちパターンの訂正

**W26の「極端が最強」は単発バイラル（重すぎ3,970）の錯覚。再現性で並べ直すと：**

```
【再現性S】ノウハウ/実務系 … 置き配731・住所708（リンク有無に関係なく安定フロア）
【中】　　 極端/恐怖 … 天気300・ヒヤリ299（3,970は再現せず）
【D】　　　あるある・内省(変化) … 35・19（配信が止まる／同ネタ重複疲労）
```

- **バイラルの鍵は「共感」ではなく「返信したくなる具体的な問い」**（重すぎ=20返信 vs 天気=2返信）。返信は相手側にも露出＝拡散ゼロ環境での擬似拡散。
- 検索流入10%超（金・日）は芽。ハッシュタグ最適化の余地。

## 4. 商品企画部｜カニバ発見とライン整理

**重大問題：「体力じゃない」を名乗る無料記事が2本あり、主力（3,480円）とテーマ・タイトルがほぼ同一。** 無料で結論が手に入ったと感じさせ、買う理由を直接破壊。note内検索でも自己競合。

### 再設計（当日のnote編集に反映）
```
【入口】失敗談（無料）…触らない＋CTA追加
【体感】走らない／積み込み（無料）…気づき1個まで＋CTA
【統合】体力じゃない系無料2本 → 「速くなるのは体力じゃない」を残し予告編化、他方は下書きへ
【主力】リポジショニング版（3,480円）＋付録
【廃止】500円 → 主力付録へ統合
```

### 編集の優先順
1. 主力差し替え → 2. 失敗談CTA → 3. カニバ解消 → 4. 走らない/積み込みCTA → 5. 500円停止 → 6. リンク飛び先確認
