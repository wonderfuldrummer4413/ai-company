## 2. 競合分析：noteカテゴリ

### 競合A：「Amazon Flex初心者ガイド」系（価格帯 500〜980円）

| 項目 | 分析 |
|------|------|
| 内容 | 登録方法、オファーの取り方、基本的な配達の流れ |
| 強み | 初心者には入りやすい、価格が安い |
| 弱み | 内容が浅い。Googleで調べれば出てくるレベル |
| 販売部数（推定） | 100〜300部 |
| レビュー傾向 | 「基本はわかったが物足りない」 |

### 競合B：「軽貨物で月収40万円達成した方法」系（価格帯 1,480〜2,980円）

| 項目 | 分析 |
|------|------|
| 内容 | 体験談ベース、稼働時間の組み方、案件選びのコツ |
| 強み | リアルな体験談で共感を得やすい |
| 弱み | 再現性が低い。「その人だからできた」感が強い。配達テクニックは薄い |
| 販売部数（推定） | 200〜500部 |
| レビュー傾向 | 「参考になったが、自分のエリアでは使えない」 |

### 競合C：「配達効率化マニュアル」系（価格帯 2,980〜4,980円）

| 項目 | 分析 |
|------|------|
| 内容 | ルート最適化、時間帯別攻略、アプリ活用法 |
| 強み | 実践的で具体性がある |
| 弱み | テキストのみで動画なし。積み込み・停車・集合住宅など現場レベルの解説が弱い |
| 販売部数（推定） | 50〜150部 |
| レビュー傾向 | 「もう少し具体的な場面別の解説が欲しい」 |

## 3. 競合分析：YouTubeカテゴリ

### 競合D：「Amazon Flex Vlog系」（チャンネル登録 1,000〜10,000人）

| 項目 | 分析 |
|------|------|
| 内容 | 1日密着、配達風景、収入公開 |
| 強み | リアリティがある、視聴者との距離が近い |
| 弱み | エンタメ寄りでノウハウの体系化がない。「見て楽しい」が「使える」ではない |
| 収益モデル | 広告収入のみ（有料コンテンツ販売なし） |
| 脅威度 | 中（直接競合ではないが、無料で得られる情報の基準を上げている） |

### 競合E：「軽貨物コンサル系YouTuber」（チャンネル登録 5,000〜30,000人）

| 項目 | 分析 |
|------|------|
| 内容 | 開業方法、案件獲得、月収報告、マインドセット |
| 強み | 権威性が高い、ファンが購入に繋がりやすい |
| 弱み | 「配達そのものの技術」には踏み込まない。コンサル誘導が目的のため、核心は出さない |
| 収益モデル | YouTube広告＋コンサル（月額3〜10万円）＋情報商材（数万円） |
| 脅威度 | 高（ターゲット層が重なる。ただし価格帯が全く異なるため棲み分け可能） |

### 競合F：「配達テクニック特化チャンネル」（チャンネル登録 500〜3,000人）

| 項目 | 分析 |
|------|------|
| 内容 | 積み込み方法、配達順序、アプリ操作のコツ |
| 強み | 実務に直結する内容、検索流入が安定 |
| 弱み | 動画が断片的で体系化されていない。「1本で完結する教材」がない |
| 収益モデル | 広告収入のみ |
| 脅威度 | 中（無料で断片的な情報は得られるが、体系的な教材としての完成度は低い） |

### 価格設定の根拠

```

  980円 ┃████████████    体験談ライト版

4,980円 ┃█               ← 当記事プレミアム版をここに設定
 数万円 ┃█               コンサル系（別カテゴリ）
```

### ベーシック版：1,980円

| 項目 | 内容 |
|------|------|
| 価格根拠 | 競合Bの上限（2,980円）より安く、競合Aの上限（980円）より高い。「安かろう悪かろう」を避けつつ、衝動買いできるライン |
| 含まれるもの | 記事本体（無料部分＋有料部分の全テキスト） |
| 返金保証 | 7日間実践条件付き全額返金 |
| 想定CVR | LP訪問者の3〜5% |
| 心理的根拠 | 「1日分の配達報酬以下で、毎日の配達が劇的に変わる」と訴求可能 |

### プレミアム版：4,980円（アップセル）

| 項目 | 内容 |
|------|------|
| 価格根拠 | 競合Cの上限と同等。動画付きなら価格正当性あり |
| 含まれるもの | 記事本体＋積み込み実演動画＋場面別攻略動画＋30日間質問対応 |
| 販売方法 | ベーシック版購入直後のサンクスページでアップセル提示 |
| 想定アップセル率 | 15〜25%（差額3,000円は「動画＋質問対応」の付加価値で十分正当化） |
| 心理的根拠 | 「たった3,000円追加で動画解説と質問し放題」のフレーム |

### 価格戦略のタイムライン

| フェーズ | 期間 | 価格施策 |
|----------|------|----------|
| ローンチ期 | 1〜2週目 | 早期購入特典として1,480円で販売（FOMO演出） |
| 通常期 | 3週目〜 | 1,980円に戻す。「ローンチ価格は終了しました」と表示 |
| 成長期 | 2ヶ月目〜 | プレミアム版を本格推進、アップセル最適化 |
| 拡張期 | 3ヶ月目〜 | コミュニティ月額980円を追加。既存購入者は初月無料 |

## 9. 最終提言

### 営業分析部長としての結論

1. **市場にチャンスがある。** 「配達テクニック×体系化×中価格帯」のポジションは明確に空いている。競合は「初心者ガイド（安い・浅い）」か「コンサル（高い・敷居が高い）」に二極化しており、当記事はその間を狙える。

2. **1,980円で出せ。** 初回は迷わずシンプルに。980円では安すぎて「質が低い」と思われ、2,980円では衝動買いを逃す。1,980円は「1日の配達報酬以下」と訴求でき、心理的ハードルが最も低い。

3. **返金保証は最大の武器。** 競合のほとんどが返金保証をつけていない。「7日間実践して効果がなければ全額返金」は、このジャンルでは圧倒的な差別化になる。返金率は実績データさえ載せておけば5%以内に収まる。

4. **アップセルで利益を取れ。** ベーシック版は集客装置、プレミアム版が利益の柱。サンクスページでの一度きりのオファーにすることで、希少性を演出しアップセル率を最大化する。

5. **初月300部を死守せよ。** これを下回ったら即座にA/Bテストを回す。価格・LP・広告クリエイティブの3変数を順番に検証し、2ヶ月目で軌道修正する。データなき改善はしない。
