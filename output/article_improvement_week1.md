## 1. タイトル改修

### 現状の問題

現タイトル「Amazon宅配がしんどい人ほど、最初に読むべき話」には**検索キーワードがゼロ**。note内検索・Google検索から誰も辿り着けない。4ヶ月で1部という結果の最大の原因はここ。

### 採用タイトル（確定）

```
Amazon配達が遅いのは体力じゃない｜1日300個配る人の「止まらない技術」
```

- 検索キーワード: 「Amazon配達 遅い」「Amazon配達 コツ」「Amazon配達 300個」
- 強み: 悩みワード（遅い）と実績（300個）を両方入れられる
- F1理論の核心「止まらない」を副題で予告
- 「遅い」という検索ワードは**すでに痛みを感じている人**が叩く = 購買意欲が高い
- 「300個」という数字が**実績とセット**で信頼を作る

### note上での設定手順

1. 記事編集画面 → タイトル欄を上記に書き換え
2. サムネイル画像の変更は不要（既存のまま）
3. 保存後、URLは変わらない（既存のインデックスを失わずに済む）

## 2. 著者プロフィール追加

### 設置場所

記事冒頭（タイトル直下）または見出し1の直後に、100〜150字の自己紹介を挿入。

### 文面（コピペ用・現在進行形バージョン）

```
はじめまして、しゅうぞうです。
現役の宅配ドライバーで、今も毎日300個前後をコンスタントに配り切っています。
ただ最初からこうだったわけじゃありません。
駆け出しの頃は1日200個が限界で、21時過ぎにヘトヘトで帰宅する毎日でした。
走っても走っても間に合わない。体力も気力も削られていく。
そんな自分が「走らずに」300個配れるようになるまでに気づいたこと・やめたこと・変えたことを、
全部この記事に詰め込みました。
```

### ポイント

- **「今も毎日300個」**を明記。過去形にしない
- 報酬・収入・契約先の会社名は一切出さない（Amazon側への配慮）
- 「駆け出しの頃は200個で限界」→ **読者＝昔の自分**という共感装置
- 「走っても走っても間に合わない」で痛みに寄り添う
- 解決策を具体的に言わず、「続きは記事本文で」の引きを作る

### 設置イメージ

```
【タイトル】Amazon配達が遅いのは体力じゃない｜1日300個配る人の「止まらない技術」

【プロフィールブロック】← ここに上記の文面を挿入

【無料部分本文】配達が遅い原因は体力でも土地勘でもなく……
```

## 3. 有料部分の見出し改修

### 原則

- 抽象語（「考え方」「最適解」）→ **具体的な数字・動作**に置き換える
- 「読めば何が得られるか」が見出しだけで分かるようにする
- サブタイトルに**時間削減量**や**配数アップ幅**を入れる

### 改修Before/After

#### ①「積み込みの考え方」

```
【Before】 積み込みの考え方
【After】  積み込み時間を15分→5分に縮める｜"取り出す順から逆算"の3ルール
```

- 数字：15分→5分（-10分）
- キーワード：「3ルール」でスキャン型読者にも刺さる

#### ②「1件あたりの時間短縮」

```
【Before】 1件あたりの時間短縮
【After】  1個あたり30秒短縮する"探さない仕組み"｜300個なら150分の差
```

- 数字：30秒 × 300個 = 150分
- 「1件」→「1個」に修正（用語を個数表記で統一）

#### ③「停車の最適解」

```
【Before】 停車の最適解
【After】  停車位置を10m変えるだけで1個30秒｜"次の配達先にも近い"の原則
```

- 数字：10m / 30秒
- X投稿5と完全に連動 → 記事を読んだ人がXで同じ話を見ると信頼が積み増しされる

#### ④「集合住宅の最適解」

```
【Before】 集合住宅の最適解
【After】  集合住宅で1棟2分を削る｜オートロック・エレベーター・部屋番号の3連戦
```

- 数字：1棟2分（5個配達なら10分、1日5棟で50分）
- 「3連戦」で戦闘感を出す

#### ⑤「雨の最適解」

```
【Before】 雨の最適解
【After】  雨の日に200個で終わらない｜"防水"ではなく"手順を削る"雨対策
```

- 数字：200個（読者の限界ライン）
- 逆張り：「防水で頑張る」ではなく「手順を省く」という発想転換を予告

#### ⑥「手渡しの最適解」

```
【Before】 手渡しの最適解
【After】  手渡し1件で失う5分を30秒に｜"インターホン前の1秒"で勝負は決まる
```

- 数字：5分→30秒
- 「インターホン前の1秒」で核心を匂わせる

### 改修後の有料部分見出し一覧（コピペ用）

```
■ 積み込み時間を15分→5分に縮める｜"取り出す順から逆算"の3ルール
■ 1個あたり30秒短縮する"探さない仕組み"｜300個なら150分の差
■ 停車位置を10m変えるだけで1個30秒｜"次の配達先にも近い"の原則
■ 集合住宅で1棟2分を削る｜オートロック・エレベーター・部屋番号の3連戦
■ 雨の日に200個で終わらない｜"防水"ではなく"手順を削る"雨対策
■ 手渡し1件で失う5分を30秒に｜"インターホン前の1秒"で勝負は決まる
■ （既存の追加セクションがあればそれも数字入り見出しに）
```

## 4. 無料部分の末尾に"チョビ見せ"を追加

### 目的

無料部分を読み終わった読者に「もう一歩だけ踏み込ませる」ための仕掛け。具体的な数字と手法名を**少しだけ**見せる。

### 設置場所

無料部分の最後、有料部分との境界の直前。

### 文面（コピペ用）

```
■ ここから先で具体的に解説します

- 積み込みを5分で終わらせる「3層ルール」
- 1個30秒を削る「2秒ルックアップ」
- 集合住宅で1棟2分を縮める「入る前の3確認」
- 雨の日に200個で終わらない「手順省略7パターン」
- 手渡しで5分を失わない「インターホン前1秒の準備」

全部、現場で自分が使っている手順です。
今日の配達からそのまま使えます。効果がなければ全額返金します。
```

### ポイント

- 手法名は**独自の造語**にする（3層ルール・2秒ルックアップ・入る前の3確認）→ 「ここでしか読めない感」を演出
- 「今日の配達からそのまま使えます」で即効性を訴求
- 最後の1行で返金保証をさりげなく差し込む（次項と連動）

## 5. 返金保証の訴求を強化

### 現状の問題

「返金保証あり」の1行だけでは弱い。読者は「どうやって返金するのか」「条件があるのか」が分からず不安になる。

### 改修案

有料部分の直前（チョビ見せの下）に以下を明記：

```
■ 返金保証について

読んでみて「自分には合わなかった」と感じたら、コメントでお知らせください。
条件なしで全額返金します。
配達ノウハウは「やってみないと効果が分からない」もの。だからこそ、
あなたの負担ゼロで試せるようにしています。
```

- **条件なし**を明言 → 「どうせ条件あるんでしょ」という疑念を消す
- **返金の手順**を具体化 → 「コメントで連絡」だけでOKと分かれば心理的障壁が消える
- 「配達ノウハウは試してみないと〜」で**返金保証を出す理由**を語る → 誠実さの演出
