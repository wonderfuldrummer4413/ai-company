## 1. タイトル改修

### 現状の問題

現タイトル「Amazon宅配がしんどい人ほど、最初に読むべき話」には**検索キーワードがゼロ**。note内検索・Google検索から誰も辿り着けない。4ヶ月で1部という結果の最大の原因はここ。

### 採用タイトル（確定）

```
Amazon配達が遅いのは体力じゃない｜1日300個配る人の「止まらない技術」
```

- 検索キーワード: 「Amazon配達 遅い」「Amazon配達 コツ」「Amazon配達 300個」
- 強み: 悩みワード（遅い）と実績（300個）を両方入れられる
- F1理論の核心「止まらない」を副題で予告
- 「遅い」という検索ワードは**すでに痛みを感じている人**が叩く = 購買意欲が高い
- 「300個」という数字が**実績とセット**で信頼を作る

### note上での設定手順

1. 記事編集画面 → タイトル欄を上記に書き換え
2. サムネイル画像の変更は不要（既存のまま）
3. 保存後、URLは変わらない（既存のインデックスを失わずに済む）

## 2. 著者プロフィール追加

### 設置場所

記事冒頭（タイトル直下）または見出し1の直後に、100〜150字の自己紹介を挿入。

### 文面（コピペ用・現在進行形バージョン）

```
はじめまして、しゅうぞうです。
現役の宅配ドライバーで、今も毎日300個前後をコンスタントに配り切っています。
ただ最初からこうだったわけじゃありません。
駆け出しの頃は1日200個が限界で、21時過ぎにヘトヘトで帰宅する毎日でした。
走っても走っても間に合わない。体力も気力も削られていく。
そんな自分が「走らずに」300個配れるようになるまでに気づいたこと・やめたこと・変えたことを、
全部この記事に詰め込みました。
```

### ポイント

- **「今も毎日300個」**を明記。過去形にしない
- 報酬・収入・契約先の会社名は一切出さない（Amazon側への配慮）
- 「駆け出しの頃は200個で限界」→ **読者＝昔の自分**という共感装置
- 「走っても走っても間に合わない」で痛みに寄り添う
- 解決策を具体的に言わず、「続きは記事本文で」の引きを作る

### 設置イメージ

```
【タイトル】Amazon配達が遅いのは体力じゃない｜1日300個配る人の「止まらない技術」

【プロフィールブロック】← ここに上記の文面を挿入

【無料部分本文】配達が遅い原因は体力でも土地勘でもなく……

## 3. 有料部分の見出し改修（実際の8章＋特典＋実践ガイド）

### 原則

- 抽象語（「〜策」「考え方」「最適解」）→ **具体的な数字・独自ワード**に置き換える
- 「読めば何が得られるか」が見出しだけで分かるようにする
- サブタイトルに**時間削減量**や**配数アップ幅**を入れる
- **記事本文に既にある数字**（25分・15〜30秒・1時間・10〜30件など）を章タイトルに上げる

### 章ごとの改修Before/After

#### 第1章

```
【Before】 第1章｜心構え策：走らず、テンポで回す
【After】  第1章｜1件を"60秒以内"で終わらせる｜降車→配達→乗車の3ステップ
```

- 数字：60秒
- 本文との整合：「1分以内配達の3ステップ」を章タイトルに引き上げ
- 読者の利得：「60秒ってできるのか？」で続きを読ませる

#### 第2章

```
【Before】 第2章｜積み込み策：丁目・サイズで「探さない」配置
【After】  第2章｜積み込みで"1日1時間の探し時間"を消す｜環境別A/Bパターン完全対応
```

- 数字：1時間（本文の「1日の探し時間は1時間以上変わります」と完全一致）
- 独自性：「環境別A/B対応」という他note に無い構成を前面に
- 読者の利得：「1時間も変わるの？」で驚かせる

#### 第3章

【Before】 第3章｜アプリ策：ナビ飛ばし＆到着時短の手順化（Flex）

- 数字：25分・1件5秒・300個（本文と完全一致）
- 独自ワード：「ナビ飛ばし」を章タイトルに引き上げ

#### 第4章

### 設置場所

無料部分の最後、有料部分との境界の直前。

### 文面（コピペ用・実際の章と連動）

```
■ ここから先で具体的に解説します

- 1件を60秒以内で終わらせる3ステップ（第1章）

- 数字が8章分並ぶことで**「これだけ変わるのか」**というスケール感が出る

- 最後の1行で返金保証をさりげなく差し込む（次項と連動）

## 5. 返金保証の訴求を強化

### 現状の問題

「返金保証あり」の1行だけでは弱い。読者は「どうやって返金するのか」「条件があるのか」が分からず不安になる。

### 改修案

有料部分の直前（チョビ見せの下）に以下を明記：

```
■ 返金保証について

読んでみて「自分には合わなかった」と感じたら、コメントでお知らせください。
条件なしで全額返金します。
配達ノウハウは「やってみないと効果が分からない」もの。だからこそ、
あなたの負担ゼロで試せるようにしています。
```

- **条件なし**を明言 → 「どうせ条件あるんでしょ」という疑念を消す
- **返金の手順**を具体化 → 「コメントで連絡」だけでOKと分かれば心理的障壁が消える
- 「配達ノウハウは試してみないと〜」で**返金保証を出す理由**を語る → 誠実さの演出

## 10. 本文に追記する数字（優先度★中・第4章と第5章のみ）

### 第4章｜歩行距離の時間計算を追加

現状の本文：
> 歩く距離が10mか1mかで、1日トータルでは大きな差です。

追加する文章（本文中「玄関の目前に止める技術」セクションに挿入）：

```
歩く距離が10mか1mかで、1日トータルでは大きな差になります。
たとえば往復20mを1件15秒のロスとしても、300個なら75分（1時間15分）。
玄関1mに止めれば、このロスがほぼゼロになります。
"ピタ止め"を意識するだけで、1日1時間以上の時間を取り戻せる計算です。
```

- 数字：1件15秒 × 300個 = 75分
- 第3章の25分よりも大きな数字 → 章の価値が跳ね上がる

### 第5章｜1棟あたりの時短計算を追加

現状の本文：
> 入りきらない時だけ「2個＋台車」で1往復完結。

追加する文章（本文中「空バッグを再利用する」セクションに挿入）：

```
2往復する人と1往復で終わる人の差は、1棟あたり3〜5分。
1日5棟の集合住宅を回るなら15〜25分のロスになります。
空バッグに入れて肩で運べば、両手が空き、1往復で配り切れます。
```

- 数字：1棟3〜5分 × 1日5棟 = 15〜25分
- 「1往復」という章タイトルのゴールと整合
