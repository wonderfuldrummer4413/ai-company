> 目的: 無料記事で読者の信頼を獲得し、有料記事「Amazon配達で月収50万円超えを目指す人へ」への購入導線を構築する

## 設計方針

| 項目 | 方針 |
|------|------|
| 無料記事の役割 | 「この人のノウハウは本物だ」と思わせる信頼獲得装置 |
| 情報の出し方 | 有料記事の「考え方（Why）」を無料で出し、「やり方（How）」は有料に誘導 |
| CTAの置き方 | 記事末尾に自然な流れで有料記事リンクを設置。押し売り感を排除 |

## 記事1：「走らない配達員」の正体

### 基本情報

| 項目 | 内容 |
|------|------|
| タイトル | **Amazon配達で1日300個配る人は「走らない」——配達が遅い本当の原因** |
| 想定文字数 | 3,000〜3,500字 |
| ターゲット | 1日150〜200個で伸び悩んでいるドライバー |
| 狙うキーワード | Amazon配達 コツ / Amazon Flex 遅い / 軽貨物 効率化 |
| 役割 | シリーズの「入口」。常識を壊して興味を引く |

### 構成

```
■ 導入（400字）
- 書き出し：「配達が速い人は走っている」——これ、完全に間違いです。
- 自分が200個時代に走り回っていたエピソード
- 300個配る先輩が「歩いていた」衝撃の事実

■ セクション1：速い人と遅い人の差は「走る速度」ではない（600字）
- 走って短縮できるのは1件あたりせいぜい5秒
- 300個配っても合計25分しか変わらない
- 一方で「止まっている時間」には1件あたり30秒以上の差がある

■ セクション2：F1のピットストップ理論（800字）
- F1ではコース上のタイム差は0.1秒、ピットストップは3秒差がつく
- 配達も同じ。移動時間は誰でもほぼ同じ。差がつくのは停車中
- 「荷物を探す」「住所を確認する」「インターホンを待つ」——ここが戦場

■ セクション3：300個配る人の5つの「しない」（800字）
- 走らない / 焦らない / 探さない / 迷わない / 止まらない
- 各項目を1〜2行で簡潔に解説（詳細は出さない）
- 「なぜこれができるか？それは"仕組み"を持っているから」

■ まとめ＋CTA（400字）
- 体力勝負だと思っていた過去の自分に伝えたいこと
- 「仕組みの作り方」を全部まとめた有料記事の紹介
- リンク設置（押し売りではなく「興味があれば」のトーン）
```

### この記事で出す情報 / 出さない情報

| 出す（無料） | 出さない（有料へ） |
|-------------|-------------------|
| 「止まっている時間」が原因という考え方 | 止まる時間を短縮する具体的な方法 |
| 5つの「しない」の概要 | 各「しない」を実現する手順・テクニック |
| F1ピットストップの比喩 | 積み込み・停車・集合住宅の最適解 |

## 記事2：積み込みで勝負は決まっている

### 基本情報

| 項目 | 内容 |
|------|------|
| タイトル | **Amazon配達が遅い人は「積み込み」で負けている——配達開始前に8割決まる話** |
| 想定文字数 | 2,500〜3,000字 |
| ターゲット | 積み込みに15分以上かかっている人、配達中に荷物を探している人 |
| 狙うキーワード | Amazon配達 積み込み / Amazon Flex 荷物 整理 / 配達 準備 |
| 役割 | 有料記事の核心「積み込みの考え方」の前振り |

### 構成

```
■ 導入（300字）
- 書き出し：配達の勝敗は、走り出す前に決まっている。
- 300個配る人の車内を見たことがあるか？
- 「整理されている」のではなく「設計されている」

■ セクション1：積み込みが配達全体を支配する理由（600字）
- 300個 × 荷物を探す時間30秒 = 150分（2時間半）のロス
- これが10秒になれば、100分の短縮 = 配達50個分の余裕
- 積み込みは「準備」ではなく「配達の第1工程」

■ セクション2：ダメな積み込みの3パターン（700字）
- ① とりあえず詰め込む → 毎回探す地獄
- ② 住所順に並べる → 一見正しいが、荷物サイズを無視して崩壊
- ③ 大きい順に積む → 下の荷物が取れない
- 各パターンの「なぜダメか」を具体的に解説

■ セクション3：正しい積み込みの「考え方」だけ教えます（600字）
- 核心：「取り出す順番」から逆算して積む
- ただし、具体的な棚割り・配置法は有料記事で解説
- 「考え方を知るだけで、明日の積み込みが変わるはず」

■ まとめ＋CTA（300字）
- 積み込みを変えるだけで1日の疲労感が激変する
- 有料記事では「5分で完了する積み込みの設計図」を公開
- リンク設置
```

### この記事で出す情報 / 出さない情報

| 出す（無料） | 出さない（有料へ） |
|-------------|-------------------|
| 積み込みが全体効率を支配するという事実 | 具体的な棚割り・配置パターン |
| ダメな積み込み3パターン | 正しい積み込みの手順・ルール |
| 「取り出す順番から逆算」という考え方 | 積み込み時間を15分→5分にする設計図 |

## 記事3：集合住宅と雨の日が「本当の実力」

### 基本情報

| 項目 | 内容 |
|------|------|
| タイトル | **Amazon配達、晴れの戸建ては誰でも速い——差がつくのは「集合住宅」と「雨の日」** |
| 想定文字数 | 2,500〜3,000字 |
| ターゲット | 集合住宅で時間をロスしている人、雨の日に効率が激落ちする人 |
| 狙うキーワード | Amazon配達 マンション / 配達 雨の日 / Amazon Flex 集合住宅 |
| 役割 | 有料記事の場面別攻略への導線。購入の最後の一押し |

### 構成

```
■ 導入（300字）
- 書き出し：晴れの日に戸建てに置き配——これは誰がやっても速い。
- 配達力の差が出るのは「条件が悪い時」
- 集合住宅と雨の日、この2つを攻略できるかで月収が変わる

■ セクション1：集合住宅で起きている「見えないロス」（700字）
- オートロックのインターホン待ち → 1件30秒〜2分
- エレベーター待ち → 1回30秒〜1分
- 部屋番号の確認ミス → 戻りで3〜5分ロス
- 1棟で5個配達 × ロス2分 = 10分。1日5棟なら50分のロス
- 「集合住宅を制する者が300個を制す」

■ セクション2：雨の日に効率が落ちる本当の理由（700字）
- 荷物の防水処理 → 1件あたり15〜30秒追加
- 視界不良・路面悪化による移動速度低下 → 全体で15〜20%遅くなる
- 最大の敵は「メンタルの消耗」→ 判断速度が落ちてミスが増える
- 雨の日に200個で終わる人と280個配れる人の差

■ セクション3：攻略の「方向性」だけ示します（500字）
- 集合住宅の攻略は「入る前の準備」で8割決まる
- 雨の日の攻略は「防水」ではなく「手順の省略」
- これ以上の具体策は有料記事で完全解説

■ まとめ＋CTA（300字）
- 「条件の悪い日に強い」＝安定して稼げるドライバー
- 有料記事では集合住宅・雨・手渡しの最適解を全パターン解説
- 「返金保証あり。効果がなければ全額返します」
- リンク設置
```

### この記事で出す情報 / 出さない情報

| 出す（無料） | 出さない（有料へ） |
|-------------|-------------------|
| 集合住宅・雨の日のロスの定量分析 | 集合住宅のオートロック攻略法 |
| なぜ効率が落ちるかの原因分析 | 雨の日の手順省略テクニック |
| 攻略の方向性（準備が8割、等） | 場面別の具体的な最適解・手順 |
