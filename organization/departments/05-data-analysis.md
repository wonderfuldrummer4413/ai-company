# 📐 データ分析部 運用マニュアル

## 役割定義

全事業活動のデータ収集・分析・予測を担当し、意思決定を数値で支える部門。

## 担当領域

### 1. エンゲージメント率の計算・分析

#### 主要指標の定義
| 指標 | 計算式 | 用途 |
|------|--------|------|
| エンゲージメント率 | (いいね+リプライ+リポスト) / インプレッション × 100 | 投稿品質の評価 |
| フォロー転換率 | 新規フォロワー / インプレッション × 100 | 認知→興味の効率 |
| note誘導率 | noteクリック数 / Threads投稿インプレッション × 100 | 集客効率 |
| 記事CVR | 購入数 / 記事PV × 100 | 販売効率 |
| 読了率 | 最後まで読んだ人 / 記事PV × 100 | 記事品質 |

#### 現状ベースライン（基準値）
```
Threadsフォロワー：246人
30日間インプレッション：222,000回
1日平均インプレッション：約7,400回
フォロワーあたりインプレッション：約903回/フォロワー（非常に高い）
```

#### 分析の着眼点
- インプレッション/フォロワー比が約903と極めて高い
  → フォロワー外への拡散力が強い（バイラル性あり）
  → フォロー転換率の改善が最大のレバレッジポイント

### 2. 投稿パフォーマンスの評価

#### 評価フレームワーク
```
S評価：エンゲージメント率 > 5% → 構造分析して再現パターン化
A評価：エンゲージメント率 3-5% → 良パフォーマンス、要素を抽出
B評価：エンゲージメント率 1-3% → 平均的、改善点を特定
C評価：エンゲージメント率 < 1% → 原因分析、同種の投稿を見直し
```

### 3. 成長予測モデル

#### フォロワー成長シミュレーション
```
【前提条件】
現在フォロワー：246人
月間インプレッション：222,000回
現在のフォロー転換率（推定）：0.11%

【シナリオ別予測】
                    フォロー転換率
                    0.11%(現状)  0.3%(改善)  0.5%(目標)
3ヶ月後（7月）      ≈320人      ≈450人      ≈580人
6ヶ月後（10月）     ≈390人      ≈850人      ≈1,250人
12ヶ月後（4月）     ≈540人      ≈1,850人    ≈3,200人

※インプレッション数はフォロワー増加に比例して成長すると仮定
```

#### 収益予測モデル
```
【変数】
- noteフォロワー（Threadsからの流入率×フォロワー数）
- 記事公開数（月間）
- 記事単価（平均）
- 購入率（CVR）

【月間収益 = noteフォロワー × 記事公開数 × 平均単価 × CVR】
```
