# 📊 CEO（経営戦略室）運用マニュアル

## 役割定義

事業全体の方向性を決定し、各部門の活動を統括する最高意思決定機関。

## 担当領域

### 1. 事業計画の策定
- 四半期ごとの事業目標設定
- 各部門への目標ブレイクダウン
- リソース配分の決定

### 2. KPI管理
- 全社KPIの設定・モニタリング
- 部門別KPIの承認
- 週次・月次レビューの実施

### 3. 収益モデルの設計
- note有料記事の価格体系
- 将来的な収益源の多角化計画
- 収支シミュレーション

### 4. 中長期ロードマップの管理
- フェーズ別の成長計画
- マイルストーンの設定と進捗管理
- ピボット判断の基準設定

## 意思決定フレームワーク

### 投資判断基準
```
ROI > 200% かつ 回収期間 < 3ヶ月 → 即実行
ROI > 100% かつ 回収期間 < 6ヶ月 → 検討・計画策定
ROI < 100% または 回収期間 > 6ヶ月 → 保留・代替案検討
```

### リスク評価
- 過去の失敗パターン（過剰投資・過信・市場読み違い）を常にチェック
- 「撤退基準」を事前に設定してから施策を開始する
- 固定費の増加を最小限に抑える（自己破産の教訓）
