# 🎯 セールス部 運用マニュアル

## 役割定義

note有料記事の販売最大化と購入導線の最適化を担当する部門。

## 担当領域

### 1. note記事の価格戦略

#### 価格帯設定
| 記事タイプ | 価格帯 | 理由 |
|-----------|--------|------|
| 入門記事（短編） | 300-500円 | 購入ハードルを下げ、初回購入を促す |
| 標準記事（中編） | 500-980円 | メインの収益源。具体的な教訓を含む |
| 深掘り記事（長編） | 980-1,980円 | 時系列の詳細分析・チェックリスト付き |
| マガジン（まとめ） | 1,980-3,980円 | シリーズをまとめたバンドル割引 |

#### 価格テスト計画
- 同カテゴリの記事で価格を変えて反応を比較
- 初月は低価格（300円）で購入者数を最大化 → 口コミ形成
- 実績ができてから段階的に価格を上げる

### 2. セールスライティング

#### 無料部分（リード文）のフレームワーク
```
Step 1: 共感（読者の痛みを言語化）
  「融資を受けたけど、返済の見通しが立たない…」

Step 2: 権威性（なぜ自分が語れるか）
  「私は実際に○○万円の融資を受け、自己破産に至りました」

Step 3: 価値提示（この記事で何が得られるか）
  「この記事では、破産に至る3年間の判断を時系列で記録しています」

Step 4: 行動喚起（購入への一押し）
  「同じ判断を迫られている方の"転ばぬ先の杖"になれば幸いです」
```

#### 効果的なタイトルパターン
```
① 数字型：「自己破産するまでの3年間で犯した5つの判断ミス」
② 告白型：「コロナ融資○○万円を溶かした経営者の記録」
③ 教訓型：「自己破産して初めてわかった"やってはいけない経営判断"」
④ 時系列型：「融資実行日から破産申立までの1,095日」
⑤ 対比型：「延命か撤退か—私が選んだ判断とその結末」
```

### 3. CVR改善・購入導線の最適化

#### Threads → note 誘導パターン
```
パターンA：記事公開告知
「noteで書きました。[1行で内容要約]
→ [noteリンク]」

パターンB：チラ見せ型
「[記事の衝撃的な一節を引用]
…続きはnoteで詳しく書いています
→ [noteリンク]」

パターンC：シリーズ連動型
「昨日のThreadsで書いた[テーマ]、
noteでは具体的な数字と判断プロセスを公開しています
→ [noteリンク]」
```

#### CVR改善チェックリスト
- [ ] 無料部分は十分に価値を提供しているか（購入の判断材料になるか）
- [ ] 無料部分が長すぎて「これで十分」と思われていないか
- [ ] 価格が内容に見合っているか
- [ ] 購入者の声・反応を記事に追記しているか
- [ ] 関連記事へのリンクがあるか（クロスセル）
