# ✍️ コンテンツ制作部 運用マニュアル

## 役割定義

jikohasan.770955ブランドの全コンテンツを企画・制作・管理する部門。

## 担当領域

### 1. Threads投稿文の作成・ストック管理

#### 投稿カテゴリ
| カテゴリ | 内容 | 頻度目安 |
|---------|------|---------|
| 経営判断の記録 | 「あの時こう考えた」系 | 週3回 |
| 教訓・学び | 失敗から得た具体的知見 | 週2回 |
| リアルタイム報告 | 再起の現在進行形 | 週2回 |
| 数字公開 | 閲覧数・収益などの透明共有 | 週1回 |

#### 投稿テンプレート
```
【構成パターンA：経営判断の記録】
[状況説明（1行）]
→ その時の判断：[何をしたか]
→ 本当はこうすべきだった：[正解の推測]
→ 今だから言える教訓：[1行でまとめ]

【構成パターンB：数字公開】
[期間]の結果報告
・[指標1]：[数値]（前期比 ±%）
・[指標2]：[数値]
→ ここから読み取れること：[分析1行]

【構成パターンC：教訓シリーズ】
自己破産して気づいた[テーマ]のこと。
[本文2-3行：具体的なエピソード]
結論：[1行の教訓]
```

#### ストック管理ルール
- 常に最低7日分（14投稿）のストックを維持
- 投稿ストックはコンテンツカレンダーで管理
- 時事ネタは当日作成・即投稿可

### 2. note有料記事の構成・執筆支援

#### 記事構成テンプレート
```
■ タイトル：[読者の痛みに刺さるタイトル]
■ 導入（無料部分）：問題提起 + 自分の経験の概要（300-500字）
■ 本編（有料部分）：
  1. 背景・状況説明
  2. 実際の判断プロセス（時系列）
  3. 結果と分析
  4. 具体的な教訓・チェックリスト
■ まとめ：読者へのアクション提案
```

#### 記事カテゴリ
- **コロナ融資シリーズ** — 融資を受けてからの判断記録
- **自己破産プロセス** — 手続きの実体験レポート
- **経営判断の失敗パターン** — 体系化した教訓集
- **再起の実況中継** — 現在の挑戦の記録

### 3. コンテンツカレンダーの運用
- 月初に翌月分のカレンダーを作成
- Threads投稿は1日2回（朝・夜）を基本
- note記事は月2-4本を目標
- 重要日程（確定申告時期・年末等）に合わせた特別コンテンツ
