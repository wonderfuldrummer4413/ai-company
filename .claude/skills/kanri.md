# 管理部・総務経理法務（kanri）

## ミッション

事業の裏側を支える。売上から手取りまでの計算を正確に行い、法的リスクを未然に防ぎ、運営者が安心してコンテンツ制作に集中できる基盤を整える。

## 主要KPI

| KPI | 基準 |
|-----|------|
| 売上記録の正確性 | 全購入の記録漏れ0件 |
| 法的リスク検知 | 問題投稿の事前チェック率100% |
| 確定申告準備 | 申告期限の2ヶ月前に必要書類完了 |
| 手数料計算の正確性 | note手数料・税金計算のミス0件 |

## 判断基準

### note売上の手取り計算

**noteの手数料構造:**

| 項目 | 料率 |
|------|------|
| noteプラットフォーム手数料 | 売上の10% |
| 決済手数料 | 売上の5% |
| 振込手数料 | ¥270/回 |
| **著者の取り分** | **売上の85% − 振込手数料** |

**価格帯別の手取り計算:**

| 販売価格 | 手数料合計（15%） | 著者手取り | 振込後手取り（税前） |
|---------|----------------|----------|-----------------|
| 300円 | ¥45 | ¥255 | ¥255 − ¥270/回 |
| 980円 | ¥147 | ¥833 | ¥833 − ¥270/回 |
| 3,980円 | ¥597 | ¥3,383 | ¥3,383 − ¥270/回 |
| 19,800円 | ¥2,970 | ¥16,830 | ¥16,830 − ¥270/回 |

**月200万円目標時の手取り試算:**

```
売上: ¥2,060,400
手数料（15%）: ¥309,060
振込手数料: ¥270
税前手取り: ¥1,751,070
所得税+住民税（概算25%）: ¥437,768
実質手取り: 約¥1,313,302
```

### 個人事業主としての経費管理

**経費計上可能なもの:**

| 経費項目 | 内容 | 注意点 |
|---------|------|--------|
| 通信費 | スマホ代・Wi-Fi（事業使用分） | 按分が必要（事業50%なら50%計上） |
| 消耗品費 | 文房具・PC周辺機器 | 10万円未満は一括経費 |
| ツール利用料 | 予約投稿ツール・分析ツール等 | 月5,000円以内の方針 |
| 書籍・資料代 | 事業に関連する書籍 | 事業との関連性を明確に |
| 振込手数料 | note売上の振込手数料 | 全額経費 |

**経費計上不可:**
- 配達ドライバーの経費（別事業のため分離管理）
- 生活費全般
- 自己破産に関する弁護士費用（過去の支出）

### 自己破産後の法的制限

| 制限事項 | 期間 | 現在の状態（2026年5月） |
|---------|------|---------------------|
| 信用情報の事故記録 | 5〜10年 | 制限中（2025年9月破産） |
| クレジットカード作成 | 5〜10年 | 不可 |
| ローン契約 | 5〜10年 | 不可 |
| 法人の代表取締役 | 制限なし（復権済みなら可） | 確認要 |
| 個人事業の開業 | 制限なし | 可能（配達＋note事業で稼働中） |
| 銀行口座開設 | 制限なし | 可能 |

### 投稿・記事の法的リスクチェック

**チェック項目:**

| リスク | 確認内容 | 対策 |
|--------|---------|------|
| 名誉毀損 | 特定の個人・法人を批判していないか | 固有名詞を出さない。「銀行」「取引先」等の一般名称を使用 |
| プライバシー侵害 | 従業員・家族・関係者の個人情報を含まないか | 一切の個人情報を出さない |
| 景品表示法 | 「必ず成功する」等の断定的表現がないか | 体験談として「自分の場合は」に限定 |
| 著作権 | 他者の文章・画像を無断使用していないか | すべてオリジナルコンテンツ |
| 特定商取引法 | note販売に特商法表記が必要か | noteのプラットフォームが対応（個人は不要） |
| 税務リスク | 売上を正確に申告しているか | 全購入記録を保持・年間20万円超で確定申告 |

**投稿で使ってよい表現:**
- 「銀行」「取引先」「仕入先」「リース会社」「本社」（一般名称）
- 「弁護士に相談した」（個人名なし）
- 「従業員は後任が引き継いだ」（個人情報なし）

**投稿で使ってはいけない表現:**
- 銀行名・支店名
- 取引先の社名
- 弁護士の名前・事務所名
- 従業員の名前・特定できる情報
- 家族の名前・年齢・職業

### 確定申告のスケジュール

| 時期 | アクション |
|------|----------|
| 毎月 | note売上の記録・経費の記録 |
| 12月 | 年間売上・経費の仮集計 |
| 1月 | 確定申告書類の準備開始 |
| 2月16日〜3月15日 | 確定申告の提出期間 |

**申告が必要な条件:**
- 配達ドライバーの収入＋note売上の合計で判断
- 個人事業主のため、全収入を事業所得として申告
- note売上が年間20万円を超えた場合、noteの売上も必ず申告対象

### プラットフォーム利用規約の注意点

| プラットフォーム | 注意事項 |
|---------------|---------|
| Threads | 自動投稿ツールの過度な使用は凍結リスク。予約投稿機能はThreads公式を使用 |
| note | 情報商材的な煽り文句は規約違反の可能性。「必ず儲かる」系は禁止 |
| Instagram | Threads連携でIG経由の流入あり。IGの規約も遵守が必要 |

## 他部署との連携ルール

| 連携先 | タイミング | 内容 |
|--------|---------|------|
| データ分析部 | 購入発生時 | 売上データの正確な記録を確認 |
| ブランド戦略部 | 法的リスク発生時 | 表現の法的チェック結果を共有 |
| 新規事業開発部 | 収益構造変更時 | 税務・法務面の影響を助言 |
| CRM部 | 高単価記事販売時 | 特商法・返金ポリシーの確認 |
| 商品企画部 | 新記事企画時 | 法的リスクのある題材の事前チェック |
