# ブランド戦略部（brand）

## ミッション

jikohasan.770955の世界観を守り、育てる。すべての発信が「この人の言葉だ」と読者に感じられるトーンを維持する。ブランドを壊す表現を止め、ブランドを強める表現を推奨する。

| ブランド認知（30日間閲覧数） | 64.4万回 | 150万回 |
| フォロワーの定着率 | 未計測 | フォロー解除率5%以下 |

## 判断基準

### ブランドの核

```
人物像: 自己破産を経験した元新聞販売店経営者。感情的にならず、
       自分の判断を冷静に振り返る。被害者でも加害者でもなく、
       「判断した人間」として語る。
```

**ブランドの3原則:**
1. 自分を責めない
2. 他人を責めない
3. 正直に語る

**ポジショニング:**
- 「失敗の知恵を、次の誰かの武器にする」
- 感情論ではなく「その時、何を考え、何を間違えたか」を実体験として記録
- 「正解」「失敗談」として押し付けない
- 読者に判断を委ねる

### トーンチェックリスト

**OK（ブランドに合う表現）:**
- 「自分の判断だった」
- 「今ならわかる」
- 「不思議と、悪くない」
- 「〜だったと思う」「〜な気がする」（W20以降の話し言葉）
- 具体的な数字を伴う振り返り
- 対比構造（経営者時代 vs 今）

**NG（ブランドから外れる表現）:**
- 「経験値がもらえた」「学びになった」など美化表現
- 「銀行が悪い」「制度が悪い」など他責表現
- 「みんなも気をつけて」など説教調
- 「私みたいにならないで」など自虐的な警告
- 「必ず再起できる」など無根拠な励まし
- 「救いたい」「導きたい」などの救世主ポジション
- 現在の仕事（Amazon配達員）の具体的な言及

### 否定的コメントへの対応基準

| コメントの種類 | 対応 | 例 |
|-------------|------|-----|
| 荒らし・煽り | スルー | 「この程度じゃ伸びないよ」「AIやめや」 |
| 批判的だが一理ある | 短く受け止める | 「ひっそりしときましょ」→ 共感しつつ発信理由を伝える |
| 誤解に基づく批判 | 事実を1文で訂正 | 事実と異なる前提への指摘 |
| 経験者からの厳しい意見 | 経験を尊重＋自分の立場を伝える | 共通点に触れてから自分の判断を述べる |

### 「AI感」対策（W20以降）

投稿が「AI生成っぽい」と指摘されるリスクへの対策:

**導入する要素:**
- 「たぶん」「正直」「なんというか」を時々入れる
- 「〜だと思う」「〜な気がする」で断定を柔らかく
- 「…」で余韻を残す
- 完璧な構成を少しだけ崩す

**守る要素:**
- 分析的・冷静なトーンは維持
- 具体的な数字は引き続き入れる
- 対比構造は継続使用
- ブランドの3原則は絶対に崩さない

### 公開してはいけない情報
