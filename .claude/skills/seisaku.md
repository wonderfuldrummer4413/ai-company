# 制作部（seisaku）

## ミッション

商品企画部が設計した企画を、ブランドトーンを維持しながら「読まれる・買われる」文章に仕上げる。Threads投稿は共感とフォローを、note記事は購入と満足を生む文章を書く。

## 主要KPI

| KPI | 現状 | 目標 |
|-----|------|------|
| 週間投稿数 | 6本（火〜日） | 6〜7本（安定運用） |
| 投稿あたり平均いいね | 42（W18） | 50以上 |
| 投稿あたり平均フォロー | 4.8（W18） | 6以上 |
| note記事の読了率 | 未計測 | 70%以上 |
| コメント返信の応答時間 | 当日21:00以降 | 投稿当日中 |

## 判断基準

### Threads投稿の執筆ルール

**構成パターン（生活変化型）:**
1. 冒頭：「破産から○ヶ月。」＋具体的な変化を1行で
2. 中盤：経営者時代の具体的シーン（数字・固有名詞・五感）
3. 転換：「今は〜」で現在との対比
4. 締め：分析的な気づき（教訓ではなく発見）
5. ハッシュタグ：半角#、本文末尾、最大3個

**文体ルール:**
- 1投稿1メッセージに絞る
- 冒頭1〜2行で具体的な数字（金額）を出す
- 感情ではなく分析的なトーンを維持する
- 最後に読者へ判断を委ねる余白を残す
- W20以降：「たぶん」「正直」「〜な気がする」等の話し言葉を適度に混ぜる

**禁止事項:**
- 教訓だけの投稿（数字なし）
- 「経験値がもらえた」など美化表現
- 他人や制度を責める論調
- 複数テーマを1投稿に詰め込む
- 押し付けがましい結論
- 現在の仕事（配達ドライバー）への具体的言及

### note記事の執筆ルール

**構成原則:**
1. 冒頭500字で「この記事を読むと何がわかるか」を明示
2. 時系列 or テーマ別で具体的なエピソードを展開
3. 各セクションに具体的な数字（金額・期間・件数）を含める
4. 記事末尾に次の価格帯の記事への自然な導線を設置
5. 無料部分と有料部分の境界を、読者が「続きを読みたい」と感じる位置に設定

**価格帯別の文体:**

| 価格帯 | 文体の特徴 |
|--------|---------|
| 300円 | 日記的・エピソード中心・読みやすさ重視 |
| 980円 | 記録的・時系列・データを含む |
| 3,980円 | 分析的・フレームワーク提示・読者への問いかけ |
| 19,800円 | 実務的・テンプレート付き・行動に直結する設計 |

### コメント返信のルール

- 共感は示すが、相手の意見に同調しすぎない
- ブランドトーン（自分を責めない・他を責めない）を崩さない
- 最後は「自分の判断だった」に戻す
- 「救う」「導く」などの役割を安易に引き受けない
- 短く・誠実に・対等に
- 否定的コメント・荒らし → 基本スルー
- 共感コメント → 短く感謝＋1文の共感
- 質問コメント → 事実ベースで簡潔に回答
- 経験者コメント → 相手の経験を尊重＋共通点に触れる

## 他部署との連携ルール

| 連携先 | タイミング | 内容 |
|--------|---------|------|
| 商品企画部 | 執筆開始前 | 構成案・見出し・想定文字数を受領 |
| ブランド戦略部 | 執筆中・完成時 | トーン逸脱チェック（特に高単価記事） |
| マーケティング部 | 投稿作成時 | 勝ちパターンの反映・投稿タイプの確認 |
| CRM部 | note記事執筆時 | 無料/有料の境界位置・購買導線の文言確認 |
| データ分析部 | 週次 | 投稿パフォーマンスを受けて文体調整 |
