# 新規事業開発部（shinki-jigyo）

## ミッション

現在の「Threads→note単品記事」モデルの次の成長エンジンを設計する。フォロワー数と収益のスケーリングに必要な新チャネル・新商品・新施策を、リスクとリターンを定量化した上で提案する。

## 主要KPI

| KPI | 現状 | 目標 |
|-----|------|------|
| 月商 | 約¥5,000/月（推定） | 月200万円 |
| 収益チャネル数 | 1（note単品記事） | 4以上（単品・マガジン・メンバーシップ・高単価） |
| 集客チャネル数 | 1（Threads） | 2以上 |
| 価格帯カバー | 2/4 | 4/4（300円〜19,800円） |

## 判断基準

### フェーズ移行の条件

| フェーズ | 移行条件 | 移行時のアクション |
|---------|---------|----------------|
| Phase 1→2 | フォロワー1,000人達成 | マガジン（1,500円）販売開始、4本目の記事追加 |
| Phase 2→3 | フォロワー3,000人達成 | メンバーシップ（980円/月）開始、高単価記事（2,980円）追加 |
| Phase 3→4 | フォロワー5,000人達成 | 19,800円記事追加、フル商品ライン稼働 |
| Phase 4完了 | フォロワー10,000人＋月商50万円 | 月200万円に向けた拡張フェーズへ |

### 新施策の評価基準

| 評価軸 | 重み | 判断基準 |
|--------|------|---------|
| 収益インパクト | 40% | 月商への貢献額（万円単位） |
| 実行コスト | 25% | 運営者の時間（配達ドライバー稼働中で月火のみフル稼働） |
| リスク | 20% | 失敗した場合の損失（金銭・時間・ブランド毀損） |
| スケーラビリティ | 15% | フォロワー増加に伴って収益が自動的にスケールするか |

### 施策の優先度マトリクス

| | 低コスト | 高コスト |
|--|---------|---------|
| **高インパクト** | **最優先で実行** | 計画的に準備 |
| **低インパクト** | 余裕がある時に実行 | 見送り |

### 月200万円の商品構成設計

```
300円記事  × 200件 = ¥60,000
980円記事  × 100件 = ¥98,000
3,980円記事 × 80件 = ¥318,400
19,800円記事 × 80件 = ¥1,584,000
合計: ¥2,060,400
```

**達成に必要なフォロワー規模（逆算）:**
```
19,800円 × 80件/月 → 月間16,000ビュー × CVR 0.5% = 80件
→ 必要フォロワー: 約30,000〜50,000人（Threads経由の流入率による）
```

### 大型コンテンツイベントの企画基準

| イベント | 時期 | 目的 | アクション |
|---------|------|------|----------|
| 破産から1年 | 2026年9月 | バイラル狙い・メディア露出 | 1年振り返りシリーズ投稿、特別記事、高単価記事のローンチ |
| フォロワー1,000人 | 2026年7月（予測） | コミュニティ形成 | 感謝投稿、マガジン発売、限定コンテンツ |
| フォロワー5,000人 | 2027年3月（予測） | メンバーシップ基盤 | メンバーシップ開始、定期配信 |
| 破産から2年 | 2027年9月 | 長期ブランド強化 | 2年目の変化の記録 |

### チャネル拡張の検討基準

| チャネル | メリット | デメリット | 開始条件 |
|---------|---------|----------|---------|
| Instagram単独投稿 | Threads流入の60%がIG経由の場合あり | 画像制作の手間 | Threads IG流入が安定して30%以上 |
| YouTube | 長尺コンテンツで信頼構築 | 顔出し/声出しの問題、編集時間 | フォロワー3,000人以上＋余裕ができた時 |
| Voicy/ポッドキャスト | 音声のみで顔出し不要 | 配達中は収録不可 | フォロワー5,000人以上 |
| メルマガ/LINE | 直接配信でプラットフォーム依存脱却 | 集客の二重手間 | メンバーシップ会員100人以上 |
| 書籍化 | 一括収益＋ブランド強化 | 出版社との交渉、長期プロジェクト | フォロワー10,000人以上＋メディア露出実績 |

### 運営者の制約条件

```
稼働可能時間:
- 月曜・火曜: 終日（全体会議・計画・記事作業・投稿作成）
- 水〜日: 朝7:30前 / 21:00以降のみ（配達稼働中）

制約:
- 顔出し・本名出しは不可
- 初期投資は最小限（有料ツール導入は月5,000円以内）
- 新チャネルの運営は月火の時間内で完結するもの優先
```
