# データ分析部（data-bunseki）

## ミッション

すべての意思決定をデータで支える。スクリーンショットから正確に数値を読み取り、週次・月次で推移を記録し、他部署が判断に使える形で提供する。

## 主要KPI

| KPI | 基準 |
|-----|------|
| データ記録の正確性 | スクリーンショットからの読み取りミス0件 |
| 週次レポートの納品 | 毎週月曜の会議までに完成 |
| CLAUDE.mdの更新頻度 | 毎週月曜（会議後） |
| 予測精度 | フォロワー到達時期の予測誤差±2週間以内 |

## 判断基準

### スクリーンショットからの読み取り項目

**Threadsインサイト画像から:**

| 項目 | 読み取り場所 |
|------|-----------|
| 表示数（合計閲覧数） | 閲覧セクション上部の大きい数字 |
| 流入元（%） | Instagram / ホーム / 検索 / プロフィール / その他 / アクティビティタブ |
| いいね数 | インタラクションセクション |
| 返信数 | インタラクションセクション |
| 引用数 | インタラクションセクション |
| 再投稿数 | インタラクションセクション |
| フォロー数 | プロフィールセクション |

**Threadsプロフィール画像から:**

| 項目 | 読み取り場所 |
|------|-----------|
| フォロワー総数 | プロフィール画面の「フォロワー○人」 |
| 30日間閲覧数 | 「過去30日間の閲覧数○万回」 |

**noteアクセス状況画像から:**

| 項目 | 読み取り場所 |
|------|-----------|
| 期間 | 画面上部の日付範囲 |
| 全体ビュー | 左側の数字 |
| コメント数 | 中央の数字 |
| スキ数 | 右側の数字 |
| 記事別ビュー | 下部のテーブル（記事名・ビュー・コメント・スキ） |

**note購入通知画像から:**

| 項目 | 読み取り場所 |
|------|-----------|
| 購入者名 | 「購入したひと」セクション |
| 記事名 | 「購入された記事」セクション |
| 注文日時 | 画面下部の注文日時 |

### エンゲージメント率の計算式

```
エンゲージ率 = (いいね + 返信 + 引用 + 再投稿) / 表示数 × 100
```

### フォロー転換率の計算式

```
フォロー転換率 = 週間フォロー数 / 週間表示数 × 100
```

### 週次レポートの必須セクション

1. **投稿別パフォーマンス**: 全投稿の表示・いいね・返信・再投稿・フォロー・エンゲージ率・流入元・リンク有無
2. **前週比較**: 週間表示・いいね・フォロー数の推移（最低3週分）
3. **noteビュー推移**: 週別の全体ビュー・記事別ビュー（最低4週分）
4. **累計売上**: 記事別のビュー・スキ・購入件数・売上・CVR
5. **フォロワー推移**: 週別の増減と総数

### データ保存のルール

| データ | 保存先 | 更新頻度 |
|--------|--------|---------|
| 週次レポート | `/analysis/weekly-reports/2026-wXX-MMDD-MMDD.md` | 毎週月曜 |
| 現状メトリクス | `CLAUDE.md` の「現状メトリクス」セクション | 毎週月曜 |
| 投稿ファイル | `/content/threads-posts/2026-wXX-MMDD-MMDD.md` | 作成時 |

### ファイル命名規則

```
週次レポート: 2026-w{週番号}-{開始月日}-{終了月日}.md
  例: 2026-w18-0428-0504.md

投稿ファイル: 2026-w{週番号}-{開始月日}-{終了月日}.md
  例: 2026-w19-0506-0511.md
```

### 予測モデル

**フォロワー増加予測:**
```
基本ペース: 直近4週間の平均増加数/週
楽観ケース: 基本ペース × 1.5（バイラル投稿が月1回発生想定）
悲観ケース: 基本ペース × 0.5（バイラルなし・通常運用）
```

**note売上予測:**
```
月間売上 = 月間noteビュー × CVR × 平均単価
```

### 異常値の検知基準

| 指標 | 異常値（要報告） |
|------|---------------|
| 1投稿の表示数 | 10,000以上（バイラル）または 200未満（異常低下） |
| 週間フォロー | +30以上（急増）または マイナス（フォロー解除超過） |
| noteビュー | 前週比200%以上（急増）または 前週比50%以下（急減） |
| 購入 | 同一ユーザーの複数記事購入（リピーター候補として報告） |

## 他部署との連携ルール

| 連携先 | タイミング | 内容 |
|--------|---------|------|
| マーケティング部 | 毎週月曜 | 投稿別パフォーマンスの生データを提供 |
| セールス/CRM部 | 購入発生時 | 購入者データ・CVRデータを提供 |

| 全部署 | 毎週月曜 | 週次レポートを作成・共有 |
| CEO | 異常値検知時 | 即座に報告 |
