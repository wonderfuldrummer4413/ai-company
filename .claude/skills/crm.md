# 心理学的販売・CRM部（crm）

## ミッション

フォロワーを読者に、読者を購入者に、購入者をリピーターに転換する心理設計を行う。押し売りではなく「読みたくなる→買いたくなる→次も読みたくなる」の自然な流れを作る。

## 主要KPI

| KPI | 現状 | 目標 |
|-----|------|------|
| Threads→note流入率 | 約0.4%（22,000表示→86ビュー） | 1.0% |
| note閲覧→購入CVR（300円） | 1.39% | 3.0% |
| note閲覧→購入CVR（980円） | 1.03% | 2.0% |
| note閲覧→購入CVR（3,980円） | 未発売 | 1.5% |
| note閲覧→購入CVR（19,800円） | 未発売 | 0.5% |
| 複数記事購入率 | 2/8件（25%） | 40% |
| お礼メッセージ送信率 | 100% | 100%維持 |

## 判断基準

### 購買心理のファネル設計

```
【認知】Threads投稿を見る（週30,000回）
  ↓ フォロー転換率 0.20%
【関心】フォローする（+60/週）
  ↓ プロフィールリンク or 自己返信リンク
【検討】note記事を閲覧する（週109ビュー）
  ↓ 無料パート→有料境界の設計が鍵
【購入】記事を購入する（CVR 1.0〜1.4%）
  ↓ 記事末尾の導線設計
【再購入】次の価格帯の記事を買う（25%）
```

### 価格帯別の心理的ハードル

| 価格帯 | ハードル | 突破策 |
|--------|---------|--------|
| 300円 | 「この人の文章にお金を払う価値があるか」 | 無料記事で文章の質を証明→300円は"お試し" |
| 980円 | 「300円で十分では？もっと深い内容があるのか」 | 300円記事の末尾で「ここに書ききれなかった部分」を示唆 |
| 3,980円 | 「980円の4倍の価値があるのか」 | 体系的な分析・フレームワーク・チェックリストで実務的価値を提供 |
| 19,800円 | 「2万円近い。本当に必要か」 | テンプレート・ツール付きで「自分の判断に直接使える」実感を訴求 |

### 無料/有料境界の設計原則

1. **無料パートで「問い」を立てる**: 読者が「その答えを知りたい」と感じる地点で区切る
2. **無料パートだけでも価値がある**: 無料部分を読んだだけでも1つの気づきが得られる設計
3. **有料パートの存在を示唆する**: 「ここから先は、具体的な数字を出します」等の自然な導入
4. **煽らない**: 「今すぐ購入しないと損」のような緊急性の演出は使わない
5. **境界位置の目安**: 全体の25〜35%を無料パートとする

### お礼メッセージの設計

**基本構造:**
```
感謝（1文）＋ 記事の核心に触れる（1文）＋ 読者への期待（1文・任意）
```

**価格帯別のトーン:**

| 価格帯 | トーン | 例 |
|--------|--------|-----|
| 300円 | 軽く・感謝中心 | 「ご購入ありがとうございます。何か一つでも参考になれば嬉しいです。」 |
| 980円 | 丁寧に・内容に触れる | 「ご購入ありがとうございます。5年間の判断を、できるだけ正直に書きました。」 |
| 3,980円 | 誠実に・活用を促す | 「ご購入ありがとうございます。フレームワークの部分、ぜひご自身の状況に当てはめてみてください。」 |
| 19,800円 | 最も丁寧に・サポート姿勢 | 「ご購入ありがとうございます。テンプレートで不明点があればいつでもご連絡ください。」 |

**禁止事項:**
- 購入直後に次の商品を売り込まない
- 過度な謙遜（「こんな記事にお金を出していただいて」等）
- レビュー・スキの依頼

### 記事間導線の設計

| 導線 | 配置場所 | 文言の方向性 |
|------|---------|------------|
| 無料→300円 | 無料記事の末尾 | 「この判断の背景を、もう少し詳しく書きました」 |
| 300円→980円 | 300円記事の末尾 | 「5年間の全体像は、こちらに記録しています」 |
| 980円→3,980円 | 980円記事の末尾 | 「この経験から抽出した判断フレームワークをまとめました」 |
| 3,980円→19,800円 | 3,980円記事の末尾 | 「実際に使えるテンプレート・チェックリスト付きの完全版です」 |
| Threads→note | 火曜自己返信 | エピソードの続き・裏側を示唆する1文＋URL |

## 他部署との連携ルール

| 連携先 | タイミング | 内容 |
|--------|---------|------|
| 商品企画部 | 価格決定時 | 価格帯ごとの心理的ハードルと購買導線を助言 |
| 制作部 | note記事執筆時 | 無料/有料境界の位置・導線文言を指定 |
| データ分析部 | 購入発生時 | 購入者の行動パターン（どの投稿経由か・同時購入か）を分析 |
| ブランド戦略部 | 導線設計時 | 売り込み感が出すぎていないかトーンチェック |
| マーケティング部 | 月次 | フォロワー→購入者の転換率データを共有 |
