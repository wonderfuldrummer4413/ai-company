# Threads運用プレイブック

## 基本方針

Threadsは「集客チャネル」として運用する。
最終目的はnote有料記事への誘導と購入。

## 運営者スケジュール

| 曜日 | 状況 | 対応可能時間 |
|------|------|------------|
| 月曜 | 休み | 終日（コンテンツ制作・分析・投稿準備） |
| 火曜 | 休み | 終日（コンテンツ制作・分析・投稿準備） |
| 水曜 | 宅配7:30-21:00 | 7:30前 / 21:00以降 |
| 木曜 | 宅配7:30-21:00 | 7:30前 / 21:00以降 |
| 金曜 | 宅配7:30-21:00 | 7:30前 / 21:00以降 |
| 土曜 | 宅配7:30-21:00 | 7:30前 / 21:00以降 |
| 日曜 | 宅配7:30-21:00 | 7:30前 / 21:00以降 |

### 運用ルール
- 水〜日の投稿は**予約投稿**で対応
- 投稿時間は**21:00固定**推奨（仕事終わりにすぐ自己返信・コメント対応可能）
- 12:00投稿は予約のみ（自己返信が遅れるためリンク投稿には不向き）
- **月・火にまとめて水〜日分の投稿を作成・予約**
- データ分析・振り返りは**月曜日**にまとめて実施
- コメント返信は仕事終わり（21:00以降）にまとめて対応

## 投稿ルール

### 投稿頻度
- 1日1回（21:00 予約投稿）
- 月・火は追加で12:00投稿も可能
- 月間目標：30本以上

### 投稿の長さ
- 推奨：140-300字
- 最大：500字（長文は例外的に）
- 1行目が最重要（フックになるか）

### 投稿のDo / Don't

#### Do（やるべきこと）
- 具体的な数字を入れる
- 1投稿1メッセージに絞る
- 読者に問いかけて終わる（エンゲージメント促進）
- 成功投稿のパターンを繰り返す
- リプライには丁寧に返す

#### Don't（やってはいけないこと）
- 複数のテーマを1投稿に詰め込む
- 感情的・攻撃的な表現
- 他のアカウントへの批判
- noteリンクの過剰投稿（3投稿に1回以下）
- ハッシュタグの乱用（3個以下）

## エンゲージメント強化策

### 1. リプライ戦略
- 自分の投稿へのリプライには24時間以内に返信
- 同カテゴリのアカウントの投稿に価値あるリプライをする
- リプライでも「分析的なトーン」を維持

### 2. 投稿フォーマット別の使い分け（実績ベース）
```
【最強】ストーリー × 具体的数字 → パターンA型（278,000回）
【強い】数字 × ストーリー + note誘導 → 告知型（5,831回）
【中程度】ストーリー × 教訓 → パターンB型（1,950回）
【弱い】教訓のみ → パターンD型（859回）
```
※ 数字が入るかどうかがリーチの分かれ目

### 3. 日課（スケジュール対応版）
```
【仕事の日（水〜日）】
□ 21:00 予約投稿が公開される
□ 21:00以降 自己返信（リンク投稿の場合）
□ 21:00以降 コメント返信
□ 21:00以降 データ確認（余裕があれば）

【休みの日（月・火）】
□ 前週のデータ分析・振り返り（月曜）
□ 今週分の投稿作成・予約
□ note記事の執筆・改善
□ コメント返信
□ 同カテゴリ投稿への有意義なリプライ
```

## パフォーマンス分析

### 週次で確認する指標
1. インプレッション数（合計・平均）
2. エンゲージメント率（投稿別）
3. フォロワー増減
4. ベスト投稿・ワースト投稿の分析
5. 投稿カテゴリ別のパフォーマンス比較

### 月次で確認する指標
1. フォロワー成長率
2. インプレッションの推移
3. noteへの誘導数・CVR
4. 投稿カテゴリの最適配分の見直し
