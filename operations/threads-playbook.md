# Threads運用プレイブック

## 基本方針

Threadsは「集客チャネル」として運用する。
最終目的はnote有料記事への誘導と購入。

## 投稿ルール

### 投稿頻度
- 平日：1日2回（朝7-9時、夜20-22時）
- 土日：0-1回（無理しない）
- 月間目標：40本以上

### 投稿の長さ
- 推奨：140-300字
- 最大：500字（長文は例外的に）
- 1行目が最重要（フックになるか）

### 投稿のDo / Don't

#### Do（やるべきこと）
- 具体的な数字を入れる
- 1投稿1メッセージに絞る
- 読者に問いかけて終わる（エンゲージメント促進）
- 成功投稿のパターンを繰り返す
- リプライには丁寧に返す

#### Don't（やってはいけないこと）
- 複数のテーマを1投稿に詰め込む
- 感情的・攻撃的な表現
- 他のアカウントへの批判
- noteリンクの過剰投稿（3投稿に1回以下）
- ハッシュタグの乱用（3個以下）

## エンゲージメント強化策

### 1. リプライ戦略
- 自分の投稿へのリプライには24時間以内に返信
- 同カテゴリのアカウントの投稿に価値あるリプライをする
- リプライでも「分析的なトーン」を維持

### 2. 投稿フォーマット別の使い分け
```
【拡散狙い】→ 短文+インパクト重視の教訓系
【フォロー狙い】→ シリーズ投稿で「続きが気になる」構造
【note誘導】→ チラ見せ型で有料記事の一部を公開
【エンゲージメント狙い】→ 質問・アンケート形式
```

### 3. 成長のための日課
```
□ 朝の投稿（7-9時）
□ 同カテゴリ投稿への有意義なリプライ3件以上
□ 夜の投稿（20-22時）
□ リプライへの返信
□ 翌日の投稿準備（ストックから選択 or 新規作成）
```

## パフォーマンス分析

### 週次で確認する指標
1. インプレッション数（合計・平均）
2. エンゲージメント率（投稿別）
3. フォロワー増減
4. ベスト投稿・ワースト投稿の分析
5. 投稿カテゴリ別のパフォーマンス比較

### 月次で確認する指標
1. フォロワー成長率
2. インプレッションの推移
3. noteへの誘導数・CVR
4. 投稿カテゴリの最適配分の見直し
