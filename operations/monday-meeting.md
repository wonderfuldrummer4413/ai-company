# 月曜全体会議アジェンダ

## 基本情報

- 開催日：毎週月曜日
- 参加部門：全7部門
- 目的：前週の振り返り＋今週の計画策定
- 必要な準備：Threadsインサイト・noteアクセス状況のスクショ

---

## アジェンダ

### 1. データ分析部｜前週の数値報告

```
□ Threads全体メトリクス
  - 合計インプレッション
  - フォロワー増減
  - 投稿数

□ note全体メトリクス
  - 全体ビュー
  - スキ数
  - 購入数・売上
```

### 2. マーケティング部｜投稿別パフォーマンス分析

```
□ 投稿別インプレッション・エンゲージメント
□ 流入元の傾向（ホーム / Instagram / プロフィール）
□ 勝ちパターンの確認・更新
□ 伸びなかった投稿の原因分析
```

### 3. セールス部｜note売上・CVR報告

```
□ 記事別ビュー数
□ 記事別購入数
□ CVR（購入率）の推移
□ Threads→note導線の効果
```

### 4. コンテンツ制作部｜今週の投稿計画

```
□ 今週のThreads投稿案（水〜日 5本分）
□ note記事の進捗・新規企画
□ 投稿タイプの配分（ストーリー×数字 / 告知 / 教訓）
```

### 5. ブランド戦略部｜トーン・方向性の確認

```
□ ブランドトーンからの逸脱がないか
□ 読者からの反応・コメントの傾向
□ 調整が必要なポイント
```

### 6. 事業開発部｜新施策・テスト案

```
□ 新しい投稿パターンのテスト案
□ 新記事テーマの提案
□ 収益拡大のアイデア（マガジン化・メンバーシップなど）
```

### 7. CEO｜最終判断・優先順位の決定

```
□ 各部門の報告を踏まえた意思決定
□ 今週の最優先タスクの確定
□ 中長期の方向性の確認
```

---

## 会議の進め方

1. CEOがThreads・noteのスクショを共有
2. 各部門が順番に分析・提案を報告
3. CEOが最終判断・今週の方針を決定

## 会議記録

会議の結果は `/analysis/weekly-reports/` に保存する。
