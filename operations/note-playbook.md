# note運用プレイブック

## 基本方針

noteは「収益化チャネル」として運用する。
Threadsで認知した読者が「深い情報を得たい」時に購入する場所。

## 記事制作フロー

### 1. 企画
```
□ テーマ選定（Threadsで反応が良かったテーマを深掘り）
□ ターゲット読者の明確化
□ 記事のゴール設定（読後に読者がどうなるか）
□ 価格帯の決定
□ 無料/有料の境界線の設定
```

### 2. 構成
```
□ アウトライン作成（見出しレベル）
□ 無料部分の範囲確定（全体の20-30%目安）
□ 有料部分の価値確認（価格に見合う情報量か）
```

### 3. 執筆
```
□ 初稿作成
□ 数字・事実の確認
□ ブランドトーンの確認
□ 法的リスクのチェック（個人名・社名が出ていないか）
```

### 4. 公開
```
□ タイトルの最終確認（セールス部のフレームワーク参照）
□ サムネイル・見出し画像の設定
□ 価格の最終設定
□ 公開
□ Threadsで告知投稿
```

## 記事タイプ別ガイド

### A. 単品記事（メイン収益）
- 文字数：3,000-8,000字
- 価格：300-1,980円
- 公開頻度：月2-4本
- 特徴：1テーマを深掘り

### B. マガジン（Phase 2以降）
- テーマ別の記事をまとめたバンドル
- 価格：単品合計の60-70%
- 例：「コロナ融資シリーズ全5本」→ 単品合計3,000円 → マガジン1,980円

### C. メンバーシップ（Phase 2以降）
- 月額500-1,000円
- 特典：限定記事 + 月1回Q&A
- 安定収益の基盤

## 無料/有料の境界線ガイド

### 無料部分で提供するもの
- 問題提起・背景説明
- 経験の概要（ダイジェスト）
- 「この記事を読むと何がわかるか」の明示
- 十分な「味見」（購入判断ができる程度）

### 有料部分で提供するもの
- 具体的な数字・金額
- 詳細な時系列記録
- 判断プロセスの深掘り分析
- 実践的なチェックリスト・フレームワーク
- 「他では読めない」一次情報

## note SEO・発見性の最適化

### タグの付け方
- noteのおすすめタグから関連性の高いものを2-3個選択
- 例：#自己破産 #経営 #起業 #お金 #コロナ融資

### 投稿タイミング
- 平日の12-13時 or 20-22時が読まれやすい
- 月末・年度末など「お金の話題」が注目される時期を狙う
